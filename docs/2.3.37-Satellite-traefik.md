### [traefik](https://github.com/traefik/traefik)

> Handle: `traefik`<br/>
> URL: [http://localhost:34373](http://localhost:34373)

![traefik screenshot](harbor-traefik.png)

Traefik (pronounced traffic) is a modern HTTP reverse proxy and load balancer that makes deploying microservices easy.

#### Starting

```bash
harbor up traefik
```

- Harbor creates relevant traefik service files [via a seed script](../.scripts/seed-traefik.ts).

#### Configuration

If Harbor's [default traefik config](../services/traefik/traefik.yml) doesn't suit your needs the expected way to configure traefik is to provide a custom configuration file.

```bash
# Path should either be global or relative to $(harbor home)
harbor config set traefik.config /path/to/your/traefik.yml
```

Apart from that, the following options can be set via [`harbor config`](./3.-Harbor-CLI-Reference.md#harbor-config):

```bash
HARBOR_TRAEFIK_HOST_PORT              80
HARBOR_TRAEFIK_HTTPS_HOST_PORT        443
HARBOR_TRAEFIK_METRICS_HOST_PORT      34372
HARBOR_TRAEFIK_DASHBOARD_HOST_PORT    34373

# Traefik version to use (docker image tag)
HARBOR_TRAEFIK_VERSION                v3
# Docker image to use for traefik
# the default one is from traefik's official docker hub
HARBOR_TRAEFIK_IMAGE                  traefik

HARBOR_TRAEFIK_CERT_EMAIL             harbor@harbor.sh

# Default Harbor setup will pre-configure services
# on the <service-handle>.${HARBOR_TRAEFIK_DOMAIN} domain
# example: ollama -> ollama.lan
HARBOR_TRAEFIK_DOMAIN                 lan

# Path should either be global or relative to $(harbor home)
HARBOR_TRAEFIK_CONFIG                 ./services/traefik/traefik.yml

# URL that'll open when you call "harbor open traefik"
HARBOR_TRAEFIK_OPEN_URL               http://localhost:34373

# deSEC API token for DNS-01 ACME challenges (see below). Empty by default.
HARBOR_TRAEFIK_DESEC_TOKEN

# How long (seconds) Traefik waits for the _acme-challenge TXT record to
# propagate before asking Let's Encrypt to verify it.
HARBOR_TRAEFIK_DESEC_PROPAGATION_TIMEOUT   180
```

#### TLS via Let's Encrypt (DNS-01 / deSEC)

By default, every service Traefik fronts gets `tls=true` on its router but no real certificate
resolver — clients see Traefik's self-signed default cert. Wiring up DNS-01 with
[deSEC](https://desec.io/) as the provider gets a real, browser-trusted **wildcard** certificate
covering `*.${HARBOR_TRAEFIK_DOMAIN}` and the bare domain, issued once and reused by every
service — no per-service ACME requests, no port 80 exposure requirement (unlike HTTP-01).

**Prerequisites:**
- `HARBOR_TRAEFIK_DOMAIN` must be a real domain (or `dedyn.io` subdomain) whose DNS is served by
  deSEC — the default `lan` value only works for LAN-only self-signed setups, DNS-01 needs a
  publicly resolvable zone.
- A deSEC API token (deSEC dashboard → Tokens).

**Setup:**

```bash
harbor config set traefik.domain yourdomain.example
harbor config set traefik.desec_token <token>
harbor config set traefik.cert_email you@example.com   # Let's Encrypt notifications
harbor down traefik && harbor up traefik
```

This is split across two files, deliberately: the parts that never vary
(`certificatesResolvers.letsencrypt.acme.{storage,dnsChallenge.provider}`, and
`entryPoints.websecure.http.tls.certResolver`) are plain YAML in
[`services/traefik/traefik.yml`](../services/traefik/traefik.yml). The parts that are per-user or
credential-only (`DESEC_TOKEN`/`DESEC_PROPAGATION_TIMEOUT` — lego reads these directly from the
process environment, there's no YAML equivalent — plus the domain/email, kept as env vars to
match the single source of truth every other service's router `Host()` rule already uses) are
`TRAEFIK_*`/`DESEC_*` environment variables in `services/compose.traefik.yml`. Traefik merges
file-based and env-based static config at runtime, so the two combine into one resolver.

**Verifying it worked:**

```bash
docker logs harbor.traefik
```

Look for the `letsencrypt` resolver initializing and a successful ACME order; on failure, lego
logs the exact deSEC/DNS-01 error (invalid token, propagation timeout, etc.).
`services/traefik/acme.json` (gitignored — it holds private key material once populated) should
grow from 0 bytes to a real certificate bundle.
